ARAW-ARAW NA GABAY PWA
=======================

This is a mobile-first Progressive Web App.

IMPORTANT:
1. A PWA must be served from HTTPS (or localhost during development) to be installable.
2. Open index.html through an HTTPS host. Opening the file directly from file:// will not provide normal PWA installation.
3. In Chrome on Android, use the Install button when available, or the browser menu > Install app/Add to Home screen.
4. The app automatically chooses the content and nature background from the selected date.
5. The current content package contains 31 verified KJV verse quotations and a 365-day selection engine. Expand data/content.json with the remaining editorially reviewed daily verses before public release.
6. Scripture is labeled as KJV. The KJV is not the original first-century manuscript. The app should retain that distinction.

NATURE IMAGES:
The sample backgrounds use Unsplash image URLs. Review the license and the specific image rights before commercial distribution. For a fully self-contained offline release, download properly licensed images into an assets folder and replace the URLs in data/content.json.

SOURCE:
The KJV quotation dataset should be checked against a trusted KJV text before final publication.
